# AnalyseDeMarché

Plateforme web de visualisation et d'analyse des **données financières du marché français**.  
Elle permet de suivre les **KPIs clés**, les **nouveautés** et les tendances du marché via une interface moderne et interactive.

---

##  Fonctionnalités

-  Tableau de bord avec indicateurs clés (KPIs) du marché français
-  Section dédiée aux nouveautés et actualités financières
-  Visualisation dynamique des données
- Interface responsive (desktop & mobile)
-  Frontend développé avec React.js
-  Backend exposant les données via API

---

## 🛠️ Technologies utilisées

**Frontend**
- React.js (Create React App)
- JavaScript (ES6+)
- HTML5 / CSS3

**Backend**
- API REST
- Traitement et exposition des données financières

##  Installation et exécution

### Prérequis

- [Node.js](https://nodejs.org/) (v14 ou supérieure)
- npm (installé avec Node.js)

### Cloner le repository

```bash
git clone https://github.com/AY00Z/AnalyseDeMarche.git
cd AnalyseDeMarche

###Lancer le Frontend (React.js)

cd ../frontend
npm install
npm start
```
